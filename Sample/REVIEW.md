## 四、物料符号标启用（v4 · 角本位）

### 4.1 背景

v3 把物料标识统一为**权威主标**（写实鹿标）。但写实标在物料场景存在结构性问题：细节多（16–24px 糊）、依赖双色（单色烫印丢层次）、语言与套件几何体系不搭。

依审定意见，重新设计并选用 **Y 形符号标（角本位）**：
鹿角本质是「**Y 形分叉**」，符号化为 **Y + 一道清溪横线**，几何加粗、直角端点。

### 4.2 与 ¥ 的三处刻意差异

| 差异 | 说明 |
| :--- | :--- |
| **只有一道横** | 人民币符号为两道横 |
| **横线下移贴杆底** | 脱离 ¥ 的居中比例 |
| **横线用进化蓝** | 语义由"货币"转为"清溪"（单色工艺时随主色同色） |

> 备选方案见 `luxi-lab-symbol-set.html`（6 案）。落选原因：01 最接近 ¥、03/05 符号感弱、04 为砖版特例、06 为无横对照。

### 4.3 三层标识体系（v4 确立）

| 层 | 标识 | 场景 | 实现 |
| :-- | :--- | :--- | :--- |
| ① 权威主标 | 写实鹿标（绿 + 蓝） | README / 官网 / 页脚 / 正式文件 | `<use href="#luxi-lab-mark">` |
| ② 产品方标 | 绿砖 + 业务图形 + 水平溪流 + 五角星 | 产品 UI / 12 + 23 产品识别 | `.brick` |
| ③ **物料符号标** | **Y + 一横**（几何加粗） | 物料小尺寸 / 单色烫印 / favicon / 水印 | `<use href="#luxi-symbol-mark">` |

### 4.4 落地清单

| 位置 | 处理 |
| :--- | :--- |
| `<defs>` | 新增 `<symbol id="luxi-symbol-mark" viewBox="0 0 48 48">`（杆/臂 4.6 · 横 3.0 · butt 端点） |
| 物料 7 处 | 工牌·工程规格版 / 名片 / 档案袋 / 随行杯 / 徽章 / 托特包 / 电脑包 → 符号标（按底材配色：白底绿标、绿底反白、深底烫金单色） |
| README 规范模版 | **保留权威主标**（文档场景） |
| VI 段 | 新增「物料符号标 · 角本位」展示卡（四配色 + 14/20/32px 阶梯） |
| 保留权威主标 | 顶栏品牌、VI 双标并排、营销页 hero、README 模版（共 4 处） |

## 六、最终方案构成

`luxi-scenario-kit-final.html`（1275 行 / 91KB）＝ 版本三骨架 + 版本一/二增量 + v4 符号标：

```
01 理念 CI     12 款正式产品矩阵 + 未来产品矩阵 · 23 款未落地产品

                 A 工牌·行政佩戴版 · 工牌·工程规格版 · 名片 · C4 档案袋
                 B ESC 键帽（版本一图样）· 随行杯 · 硬珐琅徽章
```
