## 一、三版本对照

| 维度 | 版本一 `luxi-scenario-kit.html` | 版本二 `luxi-scenario-kit-2.html` | 版本三 `luxi-scenario-kit-3.html` |
| :--- | :--- | :--- | :--- |
| 篇幅 | 2100 行 / 100KB | 1718 行 / 79KB | 796 行 / 54KB |
| 结构 | CI · VI · web · merch · tokens | CI · VI · 生产方标 · 候选方标 · merch · web · **SVG 资产库** | CI · VI · web · **UI 组件** · merch · **P0 自检** |
| 产品矩阵 | 12 款 | **16 款储备 + 8 款候选 = 24** | 12 款（JS 数据完整含 glyph） |
| 周边物料 | 6 件（描述型） | **7 件（工程规格 + 矢量）** | 3 件 |
| 交互能力 | 风险门弹窗 | 复制/下载 SVG、Toast | **LegalGate + 删除确认 + Toast** |
| 工程约束 | 自检清单 | 自检 + 数据导出 | **P0 必过 / 禁止项（最成熟）** |
| 署名 | 实验室 | **洪光华劳模创新工作室** | 实验室 |

**判定**：**版本三结构最规范**（UI 段 + P0 自检 + 禁止项 + LegalGate），作为**基底（版式与组件风格）**；
**版本二工程规格最深**（ISO 尺寸、材质牌号、工艺参数、矢量展开），作为**物料规格与主图案来源**；
**版本一覆盖最广**（数字传播物料、周边品类更多）。

## 四、最终方案构成

`luxi-scenario-kit-final.html`（1302 行 / 93KB）＝ 版本三骨架 + 版本二/一增量：

```
01 理念 CI     12 款正式产品矩阵 + 【新增】未来产品矩阵 · 23 款未落地产品（4 组 + 候选池）
02 视觉 VI     四色 / 双标等大 / 排印阶梯 / 12 产品方标
03 网页骨架    营销页 · 工作台 · 仪表盘 · 沉浸播放
04 组件交互    按钮层级 / 表单密度 / 状态标签 / Toast
05 周边物料    3 件 → 【10 件】
                 A 身份识别：工牌·行政佩戴版 · 工牌·工程规格版 · 名片 · C4 档案袋
                 B 极客硬件：ESC 键帽（剥离源启星）· 随行杯 480ml · 硬珐琅徽章 24K
                 C 携带通勤 + 数字：Tyvek 托特包 · Tyvek 电脑包 · README 规范模版
06 自检清单    P0 必过 / 禁止项 + 【新增 3 条】物料工程规格 · 工牌两版并存 · 未来池不含重名
```

**物料规格来源**（版本二）：C4 公文封套 324×229×15mm · 400gsm 原浆卡纸 · 纯铜双鸡眼扣；
工牌 ID-1 85.6×54.0×0.84mm + RFID/NFC；徽章 Ø28mm 红铜冲压 + 手工硬珐琅 + 24K 镀金；
键帽 6063-T6 铝合金 + 150# 锆砂 + 鹿溪绿阳极。
