## 四、物料符号标启用（v4 · 角本位）

### 4.1 背景

v3 把物料标识统一为**权威主标**（写实鹿标）。但写实标在物料场景存在结构性问题：细节多（16–24px 糊）、依赖双色（单色烫印丢层次）、语言与套件几何体系不搭。

依审定意见，重新设计并选用 **Y 形符号标（角本位）**：
鹿角本质是「**Y 形分叉**」，符号化为 **Y + 一道清溪横线**，几何加粗、直角端点。

### 4.2 与 ¥ 的三处刻意差异

| 差异 | 说明 |
| :--- | :--- |
| **只有一道横** | 人民币符号为两道横 |
| **横线下移贴杆底** | 脱离 ¥ 的居中比例 |
| **横线用进化蓝** | 语义由"货币"转为"清溪"（单色工艺时随主色同色） |

> 备选方案见 `luxi-lab-symbol-set.html`（6 案）。落选原因：01 最接近 ¥、03/05 符号感弱、04 为砖版特例、06 为无横对照。

### 4.3 三层标识体系（v4 确立）

| 层 | 标识 | 场景 | 实现 |
| :-- | :--- | :--- | :--- |
| ① 权威主标 | 写实鹿标（绿 + 蓝） | README / 官网 / 页脚 / 正式文件 | `<use href="#luxi-lab-mark">` |
| ② 产品方标 | 绿砖 + 业务图形 + 水平溪流 + 五角星 | 产品 UI / 12 + 23 产品识别 | `.brick` |
| ③ **物料符号标** | **Y + 一横**（几何加粗） | 物料小尺寸 / 单色烫印 / favicon / 水印 | `<use href="#luxi-symbol-mark">` |

## 八、v5 修订（符号标加粗 · 全展示位统一）

### 8.1 LOGO 用法前提（理念纠正）

LOGO ≠ 应用图标：实验室符号标**本身不含方框背景**，主色不是固定的绿，而是**与所在底材形成差异的那个颜色** ——
底为绿 → 标取源启白；底为白 → 标取鹿溪绿；底为深 → 标取标题金；单色工艺时横线随主色同色。
凡给标识加绿砖背景者属**应用图标**用法（方案 04 已据此改注为"应用图标变体（非 LOGO 用法）"）。

### 8.2 笔画加粗（终版）

| 部位 | v4 | **v5（终版）** |
| :--- | :--- | :--- |
| 两臂 / 杆 | 4.6 | **6.0** |
| 清溪横线 | 3.0 | **4.0** |

几何同时由「V 顶点汇聚」改为「**两臂各接杆顶**」，避免加粗后产生夹角尖突。

### 8.3 展示位补齐（4 处）

v4 仅切换物料 7 处；v5 补齐其余全部展示位，套件内**官方写实主标引用归零**：

| 位置 | v4 | v5 |
| :--- | :--- | :--- |
| 顶栏品牌位 | 官方主标 | **符号标** |
| VI 段 双标并排（实验室位） | 官方主标 | **符号标** |
| 营销落地页 hero | 官方主标 | **符号标** |
| README 规范模版 | 官方主标 | **符号标** |

> 官方 `LUXI LAB.svg` 仍为**品牌资产源**（Obsidian 归档 + 仓库 `assets/luxi-lab-main.svg`），用于对外正式件与工商法务场景；套件内统一采用符号标以保证视觉一致。

### 8.4 校验

- `luxi-scenario-kit-final.html`（1275 行）：符号标引用 **18** 处、官方主标引用 **0** 处；笔画 6.0 / 4.0；标签配平 OK。
- `luxi-lab-symbol-set.html`（393 行）：方案 02 同步加粗；方案 04 改注为应用图标变体；头部新增「LOGO ≠ 应用图标」用法前提。

## 九、v6 几何修正（横线盖住接缝）

### 9.1 问题

符号标由 4 条独立线段构成（两臂 + 杆 + 横线）。用户实测指出两处缺陷：

1. **接缝外露**：横线原本位于竖杆下部（y=31）且宽 4 < 杆宽 6，既不在 V 与 I 的接合处，也窄于竖杆 —— Y 的三岔路口接缝（V 与 I 交汇产生的参差边缘）**暴露在外**。
2. **颜色断裂**：横线用第二色（进化蓝）叠在绿色杆上，交叉处把 Y 在视觉上"切断"，读作缺口。

### 9.2 修正

| 项 | v5 | **v6（终版）** |
| :--- | :--- | :--- |
| 横线位置 | y=31（竖杆下部） | **y=25（Y 的三岔路口）** |
| 横线线宽 | 4（窄于杆 6） | **7（宽于杆 6）** |
| 横线长度 | x 16→32 | **x 14→34** |
| 横线颜色 | 第二色（进化蓝） | **同色（currentColor）** |

设计意图：**横线宽度大于竖杆，正好盖住 V 与 I 的接缝**，交汇处成为齐整的十字，无参差外冒；同时符号标成为**单色几何体**（颜色只由与底材的差异决定），符合「LOGO 无方框」原则。

### 9.3 副带收益

横线由竖杆下部上移至三岔路口后，**“¥ 感”显著减弱** —— 渲染复核中该符号已被识别为「Y / 分叉树形」而非货币符号，货币混淆风险自动降低。

## 十、v7 修订（两臂改羊角弧 · 恢复第二色）

### 10.1 两臂：直线 → 羊角双曲弧

用户反馈直线构成的 Y "几何形状有些突兀"。据此把两臂由直线改为**双曲弧**（先陡后扬、尖端外挑），形成羊角感：

| 部位 | v6 | **v7（终版）** |
| :--- | :--- | :--- |
| 左臂 | `M9 9L22 25`（直线） | `M23 24C22 15 16 9 8 8`（羊角弧） |
| 右臂 | `M39 9L26 25`（直线） | `M25 24C26 15 32 9 40 8`（羊角弧） |
| 杆 / 横线 | 不变 | 不变（杆 6 · 横 7 · 横线在 y=25 三岔路口盖住接缝） |

弧臂起点仍落在横线覆盖区（y∈[21.5,28.5]）内，**接缝依旧被横线盖住**。

### 10.2 配色：恢复第二色

撤销 v6 的"完全单色"，恢复原设计：

- 横线 `stroke="var(--mark-accent, currentColor)"`
- 彩色场景（白底 / 绿底）：横线取 **进化蓝 #00D2FF**，与主色形成"清溪"语义
- 单色工艺（档案袋烫金 / 深底金标）：不设变量 → 横线自动随主色，一体单色
