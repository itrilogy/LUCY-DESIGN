## 一、三版本对照

| 维度 | 版本一 `luxi-scenario-kit.html` | 版本二 `luxi-scenario-kit-2.html` | 版本三 `luxi-scenario-kit-3.html` |
| :--- | :--- | :--- | :--- |
| 篇幅 | 2100 行 / 100KB | 1718 行 / 79KB | 796 行 / 54KB |
| 结构 | CI · VI · web · merch · tokens | CI · VI · 生产方标 · 候选方标 · merch · web · **SVG 资产库** | CI · VI · web · **UI 组件** · merch · **P0 自检** |
| 产品矩阵 | 12 款 | 16 款储备 + 8 款候选 = 24 | 12 款（JS 数据完整含 glyph） |
| 周边物料 | 6 件（描述型） | 7 件（工程规格 + 矢量） | 3 件 |
| 交互能力 | 风险门弹窗 | 复制/下载 SVG、Toast | **LegalGate + 删除确认 + Toast** |
| 工程约束 | 自检清单 | 自检 + 数据导出 | **P0 必过 / 禁止项（最成熟）** |
| 署名 | 实验室 | 洪光华劳模创新工作室 | 实验室 |

**判定**：**版本三结构最规范**（UI 段 + P0 自检 + 禁止项 + LegalGate），作为**基底（版式与组件风格）**；
**版本二工程规格最深**（ISO 尺寸、材质牌号、工艺参数），作为**物料规格来源**；
**版本一覆盖最广**（数字传播物料、周边品类更多），其**实体预览样式**（工牌 / 键帽 mock）被采纳为物料标准。

## 三、图形规范统一（v3 修复 · 四类问题）

| # | 问题 | 原实现 | 修复后 |
| :--: | :--- | :--- | :--- |
| 1 | **物料上的实验室标识自绘** | 名片／工牌／托特包／随行杯／徽章各自手绘简化"标"（圆点、四芒星、拓扑图） | 统一改为 `<use href="#luxi-lab-mark">`，与 VI 段双标并排**同源同形**（共 11 处引用） |
| 2 | **键帽图样用错版本** | 版本二「双鹿角交汇 + 清溪贯通」且**剥离源启星** | 改为**版本一**图样：鹿角迎晨 + 清溪贯注 + **金色源启点**，容器用版本一 `.keycap-mock` |
| 3 | **工牌佩戴版未对齐版本一** | inline 简卡（120×150） | 引入版本一 CSS 类（`.badge-card-mock` / `.badge-lanyard-hole` / `.badge-avatar` / `.merch-preview-stage` …），140×200 白卡 + 挂孔 + 头像 + 三段式 + 投影 |
| 4 | **未来方标与 12 款不同构** | 版本二 48 视口自绘：`rect rx=10.5`、多色、**曲线**溪流 `M12 40C20 38 28 42 36 40`、四芒星 | 改用**版本三标准三件套**：`.brick`（48×48・圆角 12px）+ **24 视口单色 glyph（stroke 1.7）** + **水平** `.stream` + 五角星 `.star`；23/23 全部同构 |

**统一后的方标规范（12 款正式 + 23 款储备，共 35 款共用）**：

```html
<div class="brick">                                  <!-- 48×48 鹿溪绿圆角砖（radius 12px） -->
  <svg viewBox="0 0 24 24" stroke="currentColor" stroke-width="1.7">…业务图形…</svg>
  <span class="stream"></span>                       <!-- 底部水平溪流（height 3px / pill / 水平渐变） -->
  <span class="star"></span>                         <!-- 右上角金色五角星（clip-path polygon） -->
</div>
```

> 差异**仅在业务图形（glyph）**；砖、溪流、源启星三者完全一致。金色 / 进化蓝点缀允许出现在 glyph 内（与 12 款既有做法一致）。

## 五、最终方案构成

`luxi-scenario-kit-final.html`（1224 行 / 86KB）＝ 版本三骨架 + 版本一/二增量：

```
01 理念 CI     12 款正式产品矩阵 + 未来产品矩阵 · 23 款未落地产品（4 组 + 候选池）
02 视觉 VI     四色 / 双标等大 / 排印阶梯 / 12 产品方标
03 网页骨架    营销页 · 工作台 · 仪表盘 · 沉浸播放
04 组件交互    按钮层级 / 表单密度 / 状态标签 / Toast
05 周边物料    3 件 → 10 件
                 A 身份识别：工牌·行政佩戴版（版本一）· 工牌·工程规格版（ID-1）· 名片 · C4 档案袋
                 B 极客硬件：ESC 键帽（版本一图样）· 随行杯 480ml · 硬珐琅徽章 24K
                 C 携带通勤 + 数字：Tyvek 托特包 · Tyvek 电脑包 · README 规范模版
06 自检清单    P0 必过 / 禁止项 + 物料工程规格 · 工牌两版并存 · 未来池不含重名 · 物料主标统一
```

**校验结果**：标签配平（section 6/6 · article 25/25 · div 326/326 · svg 49/49 · span 114/114）；
23/23 未来方标使用 `.brick` 结构；曲线溪流残留 **0**；四芒星残留 **0**；主标引用 **11** 处。
