# 三版本设计套件 · 评估审阅报告

> 审阅对象：`Sample/` 目录下 OpenDesign 生成的三份场景套件
> 审阅基准：`DESIGN.md` v1.0（鹿溪设计范式）+ Obsidian `departments/lab` 品牌资产规范
> 结论产物：**`luxi-scenario-kit-final.html`**（以版本三为基底，合入版本一/二）

---

## 一、三版本对照

| 维度 | 版本一 `luxi-scenario-kit.html` | 版本二 `luxi-scenario-kit-2.html` | 版本三 `luxi-scenario-kit-3.html` |
| :--- | :--- | :--- | :--- |
| 篇幅 | 2100 行 / 100KB | 1718 行 / 79KB | 796 行 / 54KB |
| 结构 | CI · VI · web · merch · tokens | CI · VI · 生产方标 · 候选方标 · merch · web · **SVG 资产库** | CI · VI · web · **UI 组件** · merch · **P0 自检** |
| 产品矩阵 | 12 款 | **16 款生产 + 8 款候选 = 24** | 12 款（JS 数据完整含 glyph） |
| 周边物料 | 6 件（描述型） | **7 件（工程规格 + 矢量）** | 3 件 |
| 交互能力 | 风险门弹窗 | 复制/下载 SVG、Toast | **LegalGate + 删除确认 + Toast** |
| 工程约束 | 自检清单 | 自检 + 数据导出 | **P0 必过 / 禁止项（最成熟）** |
| 署名 | 实验室 | **洪光华劳模创新工作室** | 实验室 |

**判定**：**版本三结构最规范**（UI 段 + P0 自检 + 禁止项 + LegalGate 三态弹窗），适合作基底；
**版本二工程规格最深**（ISO 尺寸、材质牌号、工艺参数、矢量展开），适合作物料规格来源；
**版本一覆盖最广**（数字传播物料、周边品类更多）。

## 二、合并中裁定的 5 处冲突

| # | 冲突点 | 各版本主张 | 裁定 | 理由 |
| :--: | :--- | :--- | :--- | :--- |
| 1 | **ESC 键帽图案** | 版本一含**源启星**金色点；版本二**特别修订：剥离源启星**，改「双鹿角交汇 + 清溪贯通」 | **采纳版本二修订** | 键帽顶面面积小（14×14mm），四层语义压缩后源启星与鹿角争焦点；剥离后图腾更清晰，且不违背方标规范（方标仍保留源启星） |
| 2 | **工牌规格** | 版本三为示意；版本二给出 ISO/IEC 7810 ID-1 完整规格 | **采纳版本二** | 85.6×54.0×0.84mm 为国际 ID-1 标准，可直接交付印刷 |
| 3 | **档案袋** | 仅版本二有（C4 324×229×15mm） | **新增并入** | 用户指定项；补齐了「机密归档」这一缺失物料场景 |
| 4 | **Tyvek 包品类** | 版本一 = 电脑包；版本二 = 托特包 | **两者并存**（C 段 2 件） | 承物场景不同（通勤 vs 采购），非重复 |
| 5 | **个人署名** | 版本二档案袋烫印「洪光华劳模创新工作室审查归档」 | **改为实验室口径** | 该套件面向公开仓库（LUCY-DESIGN 为 public）；个人工作室署名应走内部分支，不进公开物料 |

## 四、最终方案构成

`luxi-scenario-kit-final.html`（1098 行）＝ 版本三骨架 + 版本二/一增量：

```
01 理念 CI     12 款正式产品矩阵（沿用版本一/三）
              + 【新增】未来产品矩阵 · 8 款孵化候选（版本二 CANDIDATE_TILES）
02 视觉 VI     四色 / 双标等大 / 排印阶梯 / 12 产品方标
03 网页骨架    营销页 · 工作台 · 仪表盘 · 沉浸播放（版本三两段子标签体系）
04 组件交互    按钮层级 / 表单密度 / 状态标签 / Toast
05 周边物料    3 件 → 【9 件】A 身份识别(工牌·名片·档案袋) · B 极客硬件(键帽·随行杯·徽章) · C 携带通勤(托特包·电脑包·README 模版)
06 自检清单    P0 必过 / 禁止项 + 【新增 2 条】物料工程规格 · 候选标注
```

**新增物料规格来源**（版本二）：C4 公文封套 324×229×15mm · 400gsm 原浆卡纸 · 纯铜双鸡眼扣；
工牌 ID-1 标准 + 双频 RFID/NFC；徽章 Ø28mm 红铜冲压 + 手工硬珐琅 + 24K 镀金。
