## 标识体系（v5）

### 用法前提：LOGO ≠ 应用图标

实验室符号标**本身不含方框背景**，因此主色不是"固定的绿"，而是**与所在底材形成差异的那个颜色**：

| 底材 | 标识取色 |
| :--- | :--- |
| 鹿溪绿底 | **源启白**（反白） |
| 源启白底 | **鹿溪绿** |
| 深林 / 深绿底 | **标题金** |
| 单色工艺（烫金 / 蚀刻 / 压凹） | 整标同色，横线随主色 |

> 凡给标识**加绿砖背景**者，属**应用图标**用法（方案 04 已改注为"应用图标变体（非 LOGO 用法）"），不作为 LOGO。

### 两层体系（套件内）

| 层 | 标识 | 场景 | 实现 |
| :-- | :--- | :--- | :--- |
| ① **实验室符号标** | **Y + 一横**（角本位 · 几何加粗 6.0 / 4.0） | 顶栏 / VI 双标并排 / 落地页 / 物料 10 件 / favicon / 水印 | `<use href="#luxi-symbol-mark">` |
| ② 产品方标 | 绿砖 + 业务图形 + 水平溪流 + 五角星 | 产品 UI / 12 + 23 产品识别 | `.brick` 内置业务图形 |

> 官方写实主标 `LUXI LAB.svg` 仍为**品牌资产源**（Obsidian 归档 + 仓库 `assets/luxi-lab-main.svg`），用于对外正式件与工商法务场景；**套件内不展示**，以保证视觉一致。

> 符号标与 <span class="mono">¥</span> 的三处差异：**只有一道横**、**横线下移贴杆底**、**横线用进化蓝**（单色工艺时随主色同色）。

## 最终方案相对版本三的增量

### 1. 理念 CI — 未来产品矩阵（23 款未落地产品）

方标储备 15 款：跃鹿 / 巡溪 / 鸣涧 / 渡越 · 灵瞳 / 寻迹 / 感界 · 澄溪 / 溯源 / 衍真 / 悟道 · 筑基 / 淬炼 / 铸规 / 墨规
孵化候选 8 款：栖林 / 青岫 / 云泽 / 隐泉 / 濯缨 / 泛舟 / 哨鹿 / 归朴

> 与 12 款正式方标**完全同构**：`.brick`（48×48・圆角 12px）+ 24 视口单色 glyph（stroke 1.7）+ **水平** `.stream` + 五角星 `.star`；**仅业务图形不同**。
> **已剔除与正式产品重名的「聆涧」**（命名与图形均不采用）。

### 2. 视觉 VI — 新增「实验室符号标 · 角本位」展示卡

四配色（绿底反白 / 白底双色 / 深底烫金单色 / 压凹单色）+ 14·20·32px 尺寸阶梯。

### 3. 周边物料 — 3 件 → 10 件

| 组 | 项目 |
| :--- | :--- |
| A 身份识别 | 工牌·**行政佩戴版**（向版本一靠齐：挂孔 + 头像 + 三段式）· 工牌·**工程规格版**（ID-1 85.6×54.0×0.84mm）· 特种纸名片 · **C4 公文封套与档案袋** |
| B 极客硬件 | ESC 键帽（**版本一图样**：鹿角 + 清溪 + 金色源启点）· 随行杯 480ml · 硬珐琅徽章 24K |
| C 携带通勤 + 数字 | Tyvek 托特包 · Tyvek 电脑包 · README 规范模版 |

> **标识统一为符号标**（v5 已把顶栏 / VI 双标并排 / 落地页 / README 模版一并切换，套件内官方主标引用归零）；配色按底材取差异色。

### 4. 自检清单

追加：物料须给标称尺寸/材质/工艺 · 工牌两版并存 · 未来池不含重名 · **标识统一用符号标且不加方框（按底材取差异色）**。

## 合并原则（一句话）

> **版式与组件取版本三；业务图形取版本二并重绘 24 视口以同构；实物预览取版本一；标识统一为符号标（无方框、按底材取差异色）；与正式产品重名的命名与图形一律剔除。**
