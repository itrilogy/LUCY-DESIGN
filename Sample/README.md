## 查看方式

直接用浏览器打开 HTML（无需构建、无外部依赖，全部内联）：

```bash
open luxi-scenario-kit-final.html      # macOS
```

顶部导航可切换 6 个场景：理念 CI · 视觉 VI · 网页骨架 · 组件交互 · 周边物料 · 自检清单。

## 最终方案相对版本三的增量

1. **理念 CI**：新增「未来产品矩阵 · 8 款孵化候选」（栖林 / 青岫 / 云泽 / 隐泉 / 濯缨 / 泛舟 / 哨鹿 / 归朴），遵循同一方标设定（绿砖 + 业务图形 + 溪流弧 + 源启星），并标注重名风险。
2. **周边物料**：3 件 → **9 件**，分三组：
   - A 身份识别：工牌与提花挂带（ID-1 标准）、特种纸名片、**C4 公文封套与档案袋**
   - B 极客硬件：ESC 键帽（**按版本二修订：剥离源启星**）、随行杯 480ml、硬珐琅徽章 24K
   - C 携带通勤：Tyvek 托特包、Tyvek 电脑包、README 规范模版
3. **自检清单**：追加「物料须给标称尺寸/材质/工艺」与「候选须标注未立项」两条。
