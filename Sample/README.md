## 查看方式

直接用浏览器打开 HTML（无需构建、无外部依赖，全部内联）：

```bash
open luxi-scenario-kit-final.html      # macOS
```

顶部导航可切换 6 个场景：理念 CI · 视觉 VI · 网页骨架 · 组件交互 · 周边物料 · 自检清单。

## 三层标识体系（v4 确立）

| 层 | 标识 | 场景 | 实现 |
| :-- | :--- | :--- | :--- |
| ① 权威主标 | 写实鹿标（绿 + 蓝，2048 视口） | README / 官网 / 页脚 / 正式文件 | `<use href="#luxi-lab-mark">` |
| ② 产品方标 | 绿砖 + 业务图形 + 水平溪流 + 五角星 | 产品 UI / 12 + 23 产品识别 | `.brick` 内置业务图形 |
| ③ **物料符号标** | **Y + 一横**（几何加粗 · 角本位） | 物料小尺寸 / 单色烫印 / favicon / 水印 | `<use href="#luxi-symbol-mark">` |

> 符号标与 <span class="mono">¥</span> 的三处差异：**只有一道横**、**横线下移贴杆底**、**横线用进化蓝**（单色工艺时随主色同色）。

## 最终方案相对版本三的增量

### 1. 理念 CI — 未来产品矩阵（23 款未落地产品）

方标储备 15 款：跃鹿 / 巡溪 / 鸣涧 / 渡越 · 灵瞳 / 寻迹 / 感界 · 澄溪 / 溯源 / 衍真 / 悟道 · 筑基 / 淬炼 / 铸规 / 墨规
孵化候选 8 款：栖林 / 青岫 / 云泽 / 隐泉 / 濯缨 / 泛舟 / 哨鹿 / 归朴

> 与 12 款正式方标**完全同构**：`.brick`（48×48・圆角 12px）+ 24 视口单色 glyph（stroke 1.7）+ **水平** `.stream` + 五角星 `.star`；**仅业务图形不同**。
> **已剔除与正式产品重名的「聆涧」**（命名与图形均不采用）。

### 2. 视觉 VI — 新增「物料符号标 · 角本位」展示卡

四配色（绿底反白 / 白底双色 / 深底烫金单色 / 压凹单色）+ 14·20·32px 尺寸阶梯。

### 3. 周边物料 — 3 件 → 10 件

| 组 | 项目 |
| :--- | :--- |
| A 身份识别 | 工牌·**行政佩戴版**（向版本一靠齐：挂孔 + 头像 + 三段式）· 工牌·**工程规格版**（ID-1 85.6×54.0×0.84mm）· 特种纸名片 · **C4 公文封套与档案袋** |
| B 极客硬件 | ESC 键帽（**版本一图样**：鹿角 + 清溪 + 金色源启点）· 随行杯 480ml · 硬珐琅徽章 24K |
| C 携带通勤 + 数字 | Tyvek 托特包 · Tyvek 电脑包 · README 规范模版 |

> **物料 7 处标识统一引用符号标 `<use href="#luxi-symbol-mark">`**（按底材配色：白底绿标 / 绿底反白 / 深底烫金）；**README 规范模版保留权威主标**（文档场景）。

### 4. 自检清单

追加：物料须给标称尺寸/材质/工艺 · 工牌两版并存 · 未来池不含重名 · **物料统一用符号标、文档用权威主标、两者不混用**。

## 合并原则（一句话）

> **版式与组件取版本三；业务图形取版本二并重绘 24 视口以同构；实物预览取版本一；物料用符号标（角本位）、文档用权威主标；与正式产品重名的命名与图形一律剔除。**
