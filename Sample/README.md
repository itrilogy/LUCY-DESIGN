## 查看方式

直接用浏览器打开 HTML（无需构建、无外部依赖，全部内联）：

```bash
open luxi-scenario-kit-final.html      # macOS
```

顶部导航可切换 6 个场景：理念 CI · 视觉 VI · 网页骨架 · 组件交互 · 周边物料 · 自检清单。

## 最终方案相对版本三的增量

1. **理念 CI**：新增「未来产品矩阵 · **23 款未落地产品**」（版式取版本三，主图案取版本二）
   - 方标储备 15 款：跃鹿 / 巡溪 / 鸣涧 / 渡越 · 灵瞳 / 寻迹 / 感界 · 澄溪 / 溯源 / 衍真 / 悟道 · 筑基 / 淬炼 / 铸规 / 墨规
   - 孵化候选 8 款：栖林 / 青岫 / 云泽 / 隐泉 / 濯缨 / 泛舟 / 哨鹿 / 归朴
   - **已剔除与正式产品重名的「聆涧」**（命名与图形均不采用）
2. **周边物料**：3 件 → **10 件**，分三组：
   - A 身份识别：**工牌·行政佩戴版**（版本三样式）、**工牌·工程规格版**（版本二 ID-1 标准）、特种纸名片、**C4 公文封套与档案袋**
   - B 极客硬件：ESC 键帽（**按版本二修订：剥离源启星**）、随行杯 480ml、硬珐琅徽章 24K
   - C 携带通勤 + 数字：Tyvek 托特包、Tyvek 电脑包、README 规范模版
3. **自检清单**：追加「物料须给标称尺寸/材质/工艺」「工牌两版并存」「未来池不含重名产品」三条。

## 合并原则（一句话）

> **版式与组件取版本三，产品主图案取版本二，物料与数字资产全量合并去重；与正式产品重名的命名与图形一律剔除。**
